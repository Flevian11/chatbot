# Learning Structure

## Courses, modules and lessons
A common LMS learning hierarchy is:
- A course is a structured learning programme focused on a subject or outcome.
- A module groups related topics within a course.
- A lesson is an individual learning unit within a module.

These are general LMS definitions. Confirm the exact LWF terminology and configuration from the live platform documentation before presenting them as formal LWF policy.

## Learning content
A course may contain lessons, learning materials, assignments and quizzes depending on how the course is configured. Do not claim that a particular course contains a specific resource unless that information appears in an approved knowledge file.

## How to answer learner questions
When a learner asks where a lesson, quiz or resource is located, provide navigation steps only if the current LWF user guide documents those steps. Otherwise ask which course or screen they are using and explain that the knowledge base does not yet contain verified navigation instructions.
