# LWF Platform Overview

## What this knowledge file covers
This is a starter knowledge document for the Learn With Flevian (LWF) learning platform. It is intentionally limited to information confirmed for the classroom project. Replace or expand it with the current, approved product documentation before deploying the assistant to learners.

## Confirmed platform context
LWF is a learning management system (LMS). The project has included Laravel as its backend framework and a React/TypeScript frontend with Inertia.js. The application has student-facing and administrator-facing areas.

## How the assistant should answer
Explain general LMS concepts when useful, but do not invent exact navigation labels, buttons, URLs, account permissions, or platform functionality. If a learner asks for a specific workflow that is not documented in the knowledge base, state that the current documentation does not confirm the steps and ask for more context or recommend contacting the LWF support team.

## Documentation maintenance
The LWF administrator or content owner should maintain this file. Add the current platform version, reviewed date, owner, and approved operational instructions as the system evolves.
